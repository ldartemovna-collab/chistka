# Чистка

Android-приложение для очистки памяти телефона: дубликаты и обработанные копии фото, серии похожих кадров, скриншоты, размытые и тёмные фото, тяжёлые видео, медиа из мессенджеров, большие файлы, загрузки, APK, архивы, дубликаты файлов, пустые папки. Свайп-режим и корзина на 30 дней.

Всё работает на телефоне, без интернета.

APK собирается автоматически: вкладка Releases → Chistka.apk (или Actions → последний запуск → Chistka-apk).
